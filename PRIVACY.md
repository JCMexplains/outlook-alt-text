# Privacy Policy for Outlook Alt Text

Last updated: January 18, 2026

## Data Collection and Usage

Outlook Alt Text is a Chrome extension that helps users add accessibility-friendly alt text to images in Outlook web emails.

### What Data We Collect

- **API Key**: Your Anthropic Claude API key is stored locally in Chrome's secure storage on your device
- **Images**: Images you paste into Outlook compose windows are temporarily processed to generate alt text

### How We Use Your Data

- **Image Processing**: Images are sent to Anthropic's Claude API for analysis and alt text generation
- **API Authentication**: Your API key is used to authenticate requests to Claude API
- **No Storage**: We do not store, log, or retain any images, alt text, or usage data on external servers
- **No Tracking**: We do not use analytics, tracking, or telemetry of any kind

### Third-Party Services

This extension uses the Anthropic Claude API to analyze images and generate alt text. When you use this extension:
- Images are sent directly to Anthropic's servers
- Anthropic's privacy policy applies to data sent to their API
- See [Anthropic's Privacy Policy](https://www.anthropic.com/privacy) for details

### Data Security

- Your API key is stored in Chrome's encrypted local storage
- All communication with Claude API uses HTTPS encryption
- No data is transmitted to any servers other than Anthropic's API

### Your Rights

You can:
- Delete your stored API key at any time by clicking the extension icon and clearing the key
- Uninstall the extension to remove all locally stored data
- Choose to skip alt text generation for any image

### Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted in the extension's GitHub repository and Chrome Web Store listing.

### Contact

For questions about this privacy policy, please open an issue on our [GitHub repository](https://github.com/JCMexplains/outlook-alt-text).
